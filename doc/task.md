# 基于 GitHub 汉化仓库的多软件配置工具 — 任务计划

更新日期：2026年11月04日。

## 1. 产品核心定位（重构后）

- **核心目标**：构建一个**基于 GitHub 汉化仓库进行多软件可视化配置与一键汉化**的桌面工具（Electron + React + TypeScript + Vite）。
- **解决痛点**：彻底替代「翻看 GitHub 仓库 README 说明、打开控制台敲命令、背命令行参数、在终端交互菜单里选数字」的繁琐流程。
- **核心设计原则**：
  1. **以 GitHub 汉化仓库为中心**：每个软件绑定一个 GitHub 汉化仓库（提供开箱即用的预设仓库，支持切换仓库、自定义 `owner/repo` 与分支、一键拉取最新仓库代码，并复用已配置的 GitHub 镜像）。
  2. **控制台参数全面可视化**：将各仓库的安装/卸载脚本参数、交互菜单功能（如语言选择、品牌标题显示、进程自动关闭、禁自动更新、技能同步、冲突插件自动停用等）全部变成卡片上的下拉框、开关与快捷按钮。
  3. **点一下就执行，拒绝说明书式弹窗与死板拦截**：
     - 取消强制阅读长篇说明的预览确认弹窗，在主页卡片上点击「一键汉化」「重新汉化」「恢复原版」即刻自动拉取仓库（若本地未就绪）并执行配置。
     - 取消死板的版本号锁死（如 Antigravity 不再锁死 `2.28.2`，本机 `v2.27.0` 及任意已安装版本均直接开放一键汉化与恢复）。
  4. **支持扩展更多软件与仓库**：提供「添加软件 / 仓库配置」能力，用户只需填入软件路径、GitHub 仓库地址与脚本入口，即可生成卡片统一管理。

状态：`[ ]` 未完成，`[x]` 已完成。

## 3. 界面与交互规格（操作台模式）

### 3.1 主页软件卡片（`ToolCard` 即操作台）

每张卡片直接承载完整配置与操作，无需点进深层弹窗：

1. **头部信息**：软件图标、名称、当前检测到的版本号、安装路径（点击可快速重选路径）、当前汉化状态徽章（`未汉化` / `已汉化` / `外部汉化`）。
2. **GitHub 仓库栏**：
   - 显示当前绑定的 GitHub 仓库（如 `Silas-02/antigravity-desktop-cn`）与缓存状态（本地就绪 / 最近同步版本）。
   - 提供 **「同步最新」** 按钮（直接从 GitHub / 镜像拉取最新分支代码）与 **「换源/配置」** 按钮。
3. **可视化参数栏**：
   - 直接在卡片内展示该仓库的常用配置项（如语言下拉、品牌标题下拉、自动关闭进程开关、Claude Desktop 的禁更新/同步技能快捷按钮），即改即存。
4. **底部一键操作栏与内联进度**：
   - 主按钮：**「一键汉化」**（已汉化时显示 **「重新汉化」** 与 **「恢复原版」**）。
   - 点击后立即执行，卡片底部内联展示实时执行进度（拉取仓库 → 执行脚本 → 校验状态）与结果提示。

### 3.2 仓库配置与日志抽屉（`DetailsDrawer`）

- 去除冗长的免责说明、限制长文与检测依据罗列。
- 聚焦实用功能：
  1. **切换 / 自定义 GitHub 仓库**：一键切换预设仓库，或手动输入 `owner/repo`、分支名、入口脚本与自定义参数。
  2. **多实例切换**：当本机存在多个安装路径时选择目标实例。
  3. **执行日志查看**：直接内联展示最近一次安装/恢复的控制台输出摘要与打开日志文件入口。
