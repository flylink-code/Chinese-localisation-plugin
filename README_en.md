# 多工具中文本地化管理软件

本项目处于规划阶段，目标是统一管理 Claude Code、Claude Desktop、Antigravity 等工具的中文本地化。

当前尚无可运行的软件、安装命令或已验证的支持版本。上述工具均为候选适配目标，具体可行性、安装渠道和版本范围需先经过调查与验证。

本文件保留为英文说明入口；完整英文版待产品范围确定后补充。当前以中文文档为准：

- [项目说明与功能规划](README.md)
- [Agent 开发约定](AGENTS.md)
- [阶段任务与验收计划](doc/task.md)
